# Matriz de acessibilidade e limites de aceite

Esta matriz consolida evidência técnica pontual. **Não é uma declaração de conformidade WCAG integral.** Erros de produto, riscos de uso e lacunas de homologação são tratados separadamente. O roteiro manual define as verificações humanas pendentes.
