# SB-07E — matriz final de riscos

Gravidade é específica à finalidade. Um bloqueador de lançamento não impede demonstração acompanhada com dados fictícios. Ausência de teste não significa defeito reproduzido. Nenhuma correção do produto está autorizada por esta matriz.
